# Kshitij Gotiwale — Portfolio

Personal portfolio website for Kshitij Gotiwale, independent art director and brand designer based in London and Mumbai.

## Stack

- **Next.js 16** — App Router, React 19, TypeScript strict
- **Tailwind CSS v4**
- **shadcn/ui**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

```bash
npm run dev        # Start dev server
npm run build      # Production build
npm run lint       # ESLint check
npm run typecheck  # TypeScript check
```
